## Introducción

Crear un blog siempre fue algo que postergué. El problema no era la falta de ideas, sino el tiempo que implica configurar todo desde cero: elegir una plataforma, diseñar el layout, escribir el código, deployar...

Decidí experimentar con herramientas de IA para ver qué tan rápido podía tener algo funcional. El resultado me sorprendió.

## Desarrollo

Usé **Astro** como framework porque genera HTML estático, es rápido y no requiere JavaScript en el cliente salvo donde lo pidas explícitamente. Para el diseño, opté por CSS puro con variables — sin frameworks, sin librerías externas.

El proceso fue más o menos así:

1. Describí el proyecto completo en un prompt detallado
2. La IA generó la estructura de carpetas, los componentes y los estilos
3. Revisé cada archivo, ajusté lo que no me gustó
4. Subí el resultado a GitHub Pages

Lo que más me gustó del enfoque: entendí cada línea de código porque tuve que revisarla. No es copiar y pegar ciegamente — es colaborar con una herramienta que acelera la parte tediosa.

## Conclusión

La IA no reemplaza saber programar. Te permite ir más rápido cuando ya sabes lo que quieres. Este blog es prueba de eso: un sitio simple, rápido, sin dependencias innecesarias, que puedo mantener yo solo.

Si tienes un proyecto que has postergado por lo tedioso del setup, prueba describírselo a una IA con tanto detalle como puedas. Los resultados pueden sorprenderte.
